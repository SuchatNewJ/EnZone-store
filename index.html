🔍 ระบบค้นหาสินค้า

ค้นหาสินค้าอย่างรวดเร็วและแม่นยำ

💡 ค้นหาด้วยหลายคำได้ เช่น "ABB C32" หรือ "schneider 25A"
⚙️ ตั้งค่าการเชื่อมต่อครั้งแรก

📋 วิธีเชื่อมต่อ Google Sheets:

  1. เปิด Google Sheets ที่มีข้อมูลสินค้า
  2. คลิก ส่วนขยาย → Apps Script
  3. ลบโค้ดเดิมออก แล้ววางโค้ดนี้: 
    function doGet(e) {
  var sheet = SpreadsheetApp
    .getActiveSpreadsheet()
    .getActiveSheet();
  var data = sheet.getDataRange().getValues();
  var json = JSON.stringify(data);

  var callback = e && e.parameter && e.parameter.callback;
  if (callback) {
    return ContentService
      .createTextOutput(callback + '(' + json + ')')
      .setMimeType(ContentService.MimeType.JAVASCRIPT);
  }

  return ContentService
    .createTextOutput(json)
    .setMimeType(ContentService.MimeType.JSON);
}
  4. คลิก ทำให้ใช้งานได้ → การทำให้ใช้งานได้ใหม่
  5. เลือก เว็บแอป
  6. ผู้ที่มีสิทธิ์เข้าถึง: เลือก "ทุกคน"
  7. คลิก ทำให้ใช้งานได้
  8. คัดลอก URL ของเว็บแอป
  9. วาง URL ในช่องด้านล่าง
